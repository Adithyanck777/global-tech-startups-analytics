# global-tech-startups-analytics
Interactive Excel dashboard analyzing global technology startup data
GLOBAL TECH STARTUPS – ANALYTICS DASHBOARD

Project Overview
An interactive Excel dashboard analyzing global technology
startup funding, valuation, domains, funding stages and
investor tiers.

Tools Used
• Microsoft Excel
• PivotTables
• PivotCharts
• Slicers
• Data Visualization

Dashboard Features
• Total Startups
• Total Funding
• Average Funding
• Average Startup Age
• Startup Domains
• Funding Stages
• Investor Tiers
• Startup Valuation
